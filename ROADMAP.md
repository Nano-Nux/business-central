# Roadmap

## Current priorities

1. Establish the backend foundation with Go Fiber, Hexagonal Architecture, and DDD.
2. Define and implement the canonical API and database contract.
3. Build merchant administration and module enablement in the admin PWA.
4. Build the portal dashboard and POS with role-based permissions.
5. Build the mobile dashboard and POS with the same workflows as the portal.
6. Add `ONLINE`-mode temporary offline operation and reliable synchronization for mobile.
7. Add `.env`-controlled `FULLY_OFFLINE` mode with no backend connection or synchronization.

## Deferred

- Public-facing marketing site development.

Future module work must specify its domain model, permissions, API behavior, portal workflow, mobile workflow, and offline implications when applicable.
