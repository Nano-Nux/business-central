| Catalog operations                         | Implemented                                | Merchant-only category, product, variant, unit, conversion, price-list, and promotion definition/scope/code mutations persist locally and synchronize while disconnected; catalog administration is hidden from staff; each price list permits one price per sellable variant                                                                                                                                                                                                                                                             |
| Images                                     | Partial                                    | Product, variant, shop-logo, and repair forms accept one URL, one Google Drive sharing URL, or direct files stored in SeaweedFS. Shop-logo changes can be selected offline: the resized file is stored in the scoped outbox, uploaded to SeaweedFS on reconnect, and then applied through versioned shop settings. Product/variant/repair image mutations remain online-only.                        |
| Storage stock checking                     | Implemented for portal scope               | Responsive view-only Operations → Storage table for merchant/staff with page-size and indexed backend pagination, global search, controls above every data-column header, server-side partial filters/sorting, visual parent → child catalog paths, RETAIL sell price, optional manufacture/expiry dates, staff shop scope, and merchant-only original price/profit                                                                                                                                                                       |
| Stock receipt/history                      | Implemented                                | Receivable purchase-order selection, immutable receipts/FIFO costs, optional API reuse of the variant's latest receipt cost after its first stock-in, and responsive, paginated resolved movement history; staff stock-in hides original price and staff history hides unit cost                                                                                                                                                                                                                                                          |
| POS catalog complexity                     | Partial                                    | SIMPLE product creation attaches category, unit, and variant attributes while the backend creates one standard variant; pricing and stock-in hide variant/SKU terminology. COMPLEX retains explicit variants. SIMPLE offline creation awaits atomic sync support.                                                                                                                                                                                                                                                                         |
| POS                                        | Implemented for temporary offline          | Local quote/preview, provisional receipt, complete snapshots, durable typed operation, local stock reservation, canonical reconciliation, and visible mismatch review; provider authorization remains pending by the approved third-party payment exception                                                                                                                                                                                                                                                                               |

| Barcode search and scanning                | Implemented for portal scope               | Product/variant search, camera/image and live browser scanning, automatic native Flutter scanning in the mobile HTTP WebView, HID/keyboard scanner input, POS lookup, direct stock-asset checkout, and a tenant/shop-scoped stock barcode administration page are implemented                                                                                                                                                                                                                                                             |
| Shop customers                             | Partial                                    | Canonical customer list with sales/repair counts and an online merchant-owner-only edit page; paired mobile editing remains pending                                                                                                                                                                                                                                                                                                                                                                                                       |

| Transaction history                        | Implemented for portal scope               | Separate responsive, shop-scoped chronological view with indexed server pagination, complete canonical checkout details, item pricing, FIFO cost/profit, explicit pending-cost states before inventory fulfillment, payments, and refunds; the detail action is hidden from staff list rows                                                                                                                                                                                                                                               |
| Stock movement detail                      | Implemented for portal scope               | Complete resolved ledger event with product/SKU, unit, locations, current balances, receipt or checkout context, and FIFO cost layers                                                                                                                                                                                                                                                                                                                                                                                                     |
| Repair                                     | Implemented for backend/portal scope       | Repeatable work items support repeatable issues, optional conditions, and per-device waiting time entered as calendar days or an end date. Merchant owners manage shop-scoped Issue and Condition presets. Dynamic forms, billing, payments/refunds, inventory parts, images, lifecycle records, and printable financial details remain implemented. |
| Staff accounts                             | Implemented                                | Merchant-managed staff creation, activation, and exactly-one-shop assignment                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Promotions                                 | Implemented for temporary offline          | Promotion CRUD, schedules, usage limits, product/variant scopes, and codes use durable deferred replay; applied authoritatively in POS and repair workflows                                                                                                                                                                                                                                                                                                                                                                               |
| Invoices                                   | Implemented                                | Canonical sales and repair-ticket invoice list/detail with stored currency, direct PDF download, browser print, monochrome image proof, ESC/POS image printing, repair receipts available in every ticket/payment status, shop-controlled logo visibility, and default-off shop preferences for displaying device type and brand on repair invoices.                                                                                                                                                                                      |
